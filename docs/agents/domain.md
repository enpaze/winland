# Domain Docs

Read these before exploring. A missing file is skipped silently.

- `GLOSSARY.md` at the repo root: the glossary.
- `docs/adr/README.md`: decisions by area. Read the ADRs it lists for the area you are about to work in, and keep the index in step when an ADR is added, rewritten, or deleted.

## Vocabulary

Name a domain concept (in a hypothesis or a test name) with the term `GLOSSARY.md` defines, never a synonym it avoids. A concept the glossary lacks is either language the project does not use (reconsider) or a gap in the glossary.

## ADR conflicts

An output that contradicts an ADR says so:

> _Contradicts ADR 0004 (Winland runs elevated) — but worth reopening because…_
